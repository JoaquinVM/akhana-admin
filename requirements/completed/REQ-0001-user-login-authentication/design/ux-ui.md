# UX/UI Design - REQ-0001: Login y Autenticación de Usuarios

## UI Impact: NONE

Este requerimiento es de naturaleza 100% backend (servicios REST, Spring Security, JPA y scripts de base de datos). 
No introduce ni modifica pantallas o componentes visuales en la capa `frontend/`.

- **Stitch MCP:** Omitido (no aplica diseño gráfico ni mockups).
- **Consumo:** Las respuestas HTTP JSON y códigos de estado (200, 401) servirán de contrato para el frontend en un requerimiento posterior de interfaz de usuario.
