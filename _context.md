# Contexto del Repositorio Raíz: Akhana Admin

## Propósito y Visión General
Espacio de trabajo del proyecto **Akhana Admin**, diseñado bajo el framework de **Developer Assistant Agéntico Autónomo y Supervisado**.

## Estructura de Directorios
- `frontend/`: Aplicación de interfaz web (Admin UI). [Ver contexto](file:///Users/joaquin/Documents/Akhana%20Admin/frontend/_context.md).
- `backend/`: Capa de servicios backend (incluye `akhana-admin` Spring Boot). [Ver contexto](file:///Users/joaquin/Documents/Akhana%20Admin/backend/_context.md).
- `database/`: Scripts SQL, migraciones y esquemas canónicos. [Ver contexto](file:///Users/joaquin/Documents/Akhana%20Admin/database/_context.md).
- `project/`: Memoria viva del proyecto, convenciones globales y ADRs. [Ver contexto](file:///Users/joaquin/Documents/Akhana%20Admin/project/PROJECT.md).
- `requirements/`: Directorio estructurado del ciclo de vida de requerimientos (`active/` y `completed/`). [Ver catálogo](file:///Users/joaquin/Documents/Akhana%20Admin/requirements/README.md).
- `.agents/`: Definiciones de agentes de IA, skills y reglas del asistente.
- `.antigravity/`: Estado operativo y memoria de sesión activa.

## Regla Context First
Para entender o modificar cualquier parte del sistema, navega siempre primero a los archivos `_context.md` de la carpeta en cuestión.
